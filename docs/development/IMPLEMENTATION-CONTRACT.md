# Backup/recovery implementation contract

Status: implementation in progress, not a release. The owner's complete development handoff is the product authority. Preserve upstream MIT LICENSE and existing behavior. Repo /root/Projects/windows-pitr-config, branch feat/user-backup-recovery, upstream a6595a87e0aec337b781a2962218c501bba0a113. Target Windows PowerShell 5.1, no end-user modules, installers, network dependency, credential persistence, snapshot mutations, ACL bypasses, deletion or silent overwrite. Agents never git clean/reset/checkout/stash/commit/push. Shared files parent-owned.

## Source layout / module loading
`src/backup/Platform.ps1`, `Manifest.ps1`, `Backup.ps1`, `Recovery.ps1` contain only functions/types, no top-level work except guarded Add-Type. They are dot-sourced in this order by `src/backup/Entry.ps1` and UI worker runspaces. Modules must not require WPF. ASCII executable sources, shipped CRLF UTF8 no BOM. Upstream CMD remains UTF8 explicitly loaded. `src/backup/Ui.ps1` and `Localization.ps1` are presentation. Portable package may use small sidecars initially; single CMD assembly is a later packaging optimization, not duplicate engine code.

## Shared APIs (named arguments)
Platform:
- Get-PitrProfiles: objects Sid, Path, DisplayName, IsPublic, SourceVolumeId. Normal profiles + Public, default OS volume only. Expose inaccessible profiles, do not silently omit.
- Get-PitrVolumeIdentity -Path: object Kind (Local/Network), VolumeId, CanonicalPath, FileSystem, AvailableBytes, Warnings. Resolve nearest existing ancestor, stable Windows volume ID and final path; mapped network drives explicit Network, fail closed unresolved. No C: assumptions.
- Test-PitrDestination -Destination -Sources [string[]] -RequiredBytes [long=0]: throws on unsafe/unwritable/same-OS-volume/nested/alias/insufficient; returns identity. Probe unique temp own file only. Reject source/destination reparse ancestors fail closed where stronger resolution unavailable.
- Get-PitrSourceRoots -Profiles [object[]] -Scope (Complete/Personal/Custom) -CustomPaths [string[]]: objects Id, Path, ProfileSid, SourceVolumeId, Category (Profile/Personal/Extra), DisplayName. Stable GUID or hash Id; avoid collisions/overlap. Custom must not silently include all profiles.
- Test-PitrSafePath -Root -RelativePath: returns canonical child string, rejecting traversal, ADS, rooted relative names, device paths, reparse ancestors and invalid Windows components. Existing root must not be a reparse point. Works with native paths in synthetic Linux tests; enforce Windows name rules independently.

Manifest (owned with Backup):
- Read-PitrManifest -ManifestPath: validate schema and types and uniqueness/paths, return object. No evaluation. Treat untrusted, reject unsupported versions and oversized input.
- Write-PitrManifest -ManifestPath -Manifest: transactional unique temporary and replacement, never false complete.
- Get-PitrHash -Path: streaming SHA256 string, source before/after stats where relevant handled by caller.

Backup:
- New-PitrBackup -Sources [object[]] -Destination -Scope (Complete/Personal/Custom default Complete) -Progress [scriptblock optional] -Cancellation [object optional] -RecoverySource [string optional]: validates destination then creates unique job directory; returns manifest object incl ManifestPath (runtime convenience, not relied on after move).
- Resume-PitrBackup -ManifestPath -Progress -Cancellation: validate previously copied hashes and re-inventory source; never mutate Verified generations.
- Test-PitrBackup -ManifestPath -Mode (Quick/Full default Full) -Progress -Cancellation: read/validate files, statuses, write state and return manifest.
- Install-PitrRecoveryPackage -BackupRoot -RecoverySource: copies trusted application-owned code only, launcher + README + SHA256 package inventory. Caller passes application source root, not user-selected source content. If unavailable backup incomplete readiness, never false successful.
Progress receives object Phase, Profile, File, FilesProcessed, BytesProcessed, TotalBytes, ErrorCount. Cancellation is a synchronized hashtable with Cancelled bool. Check between streaming chunks/files. Interrupted state preserves prior files. Live view explicitly not application consistent. Unsupported reparse/cloud/EFS/ADS/etc must be recorded with warnings/failed inventory, never skipped silently.

Recovery:
- Compare-PitrBackup -ManifestPath -Mappings [hashtable] -Deep [switch] -Progress -Cancellation: returns report object SchemaVersion, BackupId, ScanComplete, Entries, Summary, Warnings. Mappings keys Source.Id -> explicit approved current root. No automatic display-name mapping. Without mapping propose SID evidence read-only but do not restore. Entries include Id, SourceId, RelativePath, BackupRelativePath, CurrentPath, Classification (Missing/Different/Identical/LikelyIdentical/CurrentOnly/Unknown), IsAdvanced, IsSensitive, Error. Must include current-only items, traversal failures become Unknown/incomplete. Deep validates current hash and backup integrity before claiming Identical.
- Restore-PitrFiles -ManifestPath -Mappings [hashtable] -EntryIds [string[]] -AlternateRoot [string optional] -Conflict (Skip/Alongside/Replace default Skip) -Execute [switch] -AllowAdvanced [switch] -Progress -Cancellation: default dry-run; selection explicit, default missing personal only, reject sensitive/startup executables, AppData requires explicit advanced consent preferably alternate root. Recompute comparison and validate backup hash before copying. Approved root required, no raw original absolute path restoration. Conflicts never overwritten silently; explicit Replace preserves current bytes in unique conflict store then temp-copy/verify/atomic swap. Log each action with verification. Return SchemaVersion, BackupId, DryRun, Entries, Summary, Complete.
- Export-PitrReport -Report -Path -Format (Json/Csv/Text): local safe output, CSV formula mitigation/escaping and privacy warning in docs.

## Manifest schema v1 (PascalCase exact)
Top: SchemaVersion=1, BackupId=GUID, ComputerIdentity, OsVersion, ApplicationVersion, CreatedUtc, StartedUtc, CompletedUtc nullable, State, Scope, SourceView='Live', Consistency='LiveNotApplicationConsistent', Sources=array, Entries=array, Exclusions=array, Warnings=array, Counts, RecoveryPackage, DestinationIdentity. State: Planned/Running/Interrupted/CopyCompleted/Verifying/Verified/CompletedWithWarnings/Failed. Strong Verified means every selected object accounted and copied file integrity Full verified; Consistency remains separate, skipped objects forbid strongest status. Counts include Expected, Copied, Verified, Skipped, Failed, Bytes.
Sources: Id, Path (original absolute), ProfileSid nullable, SourceVolumeId, Category, DisplayName.
Entries: Id unique string, BackupId, SourceId, OriginalPath, ProfileSid nullable, RelativePath, BackupRelativePath ('profiles/<sourceId>/<relative>' or 'extra-folders/...'), Type (File/Directory/ReparsePoint/Unsupported), Length int64, LastWriteUtc ISO string, Attributes string, SourceVolumeId, CopyStatus (Pending/Copied/Skipped/Failed), VerificationStatus (Pending/QuickVerified/FullVerified/Failed), Sha256 nullable, Error nullable, SourceView='Live', IsAdvanced bool, IsSensitive bool. Directories recorded including empty ones; unsupported objects distinct. Inventory failures represented explicitly. All filenames remain Explorer accessible. Backup data never interpreted as code.

## Gates / decisions
Full independent backups first, no incrementals. No automatic VSS implementation without validated requester/writer lifecycle: explicit live-copy fallback and incomplete-file reporting permitted by owner. Never provision VM; Windows Actions disposable fixture tests then owner live Windows/PITR validation. No actual PITR claim without actual rollback evidence. Localization all ten languages with unreviewed translation label. All old PITR features preserved; no automatic recovery restart or restore. Main original UAC behavior may need separate regression repair, not wholesale rewrite.

Each implementation agent uses strict vertical TDD, real PowerShell execution, standalone tests/<Lane>.Tests.ps1 assertions with nonzero failure, captures actual red/green in docs/development/<LANE>-EVIDENCE.md. Windows-only behavior marked pending until real CI. Parent reviews exact diff and reruns integrated tests before any completion/release.
